# FPV バンドモニタ 液晶版（XIAO ESP32-C5 + ILI9341）

[fpv-band-monitor-c5](https://github.com/zubon2003/fpv-band-monitor-c5)（PC 版）の解析と画面を、
ESP32-C5 単体で動くように [ESP-SDR](https://github.com/ESPARGOS/esp-sdr) ファームに組み込んだもの。
PC は不要で、2.8" ILI9341 + XPT2046 タッチ液晶にスペクトラム・ウォーターフォール・実測中心周波数を表示する。
**アナログ FPV の映像電波（FM-ATV）専用**。

追加したコードは `main/fpv/` にまとまっている。ESP-SDR 側の変更は
`main/families/c5_c6_c61/receiver.c` に、無線を直接操作する小さな関数群（`sdr_hw_*`）と、
起動時にモニタへ入る分岐を足しただけ。

## 表示モード

| モード | チャンネル | 掃引範囲 | ホップ数 |
|---|---|---|---|
| 4CH（既定） | E2 / E1 / F3 / F5 | 5670〜5835 MHz | 9 |
| 3CH | E1 / F1 / F4 | 5690〜5815 MHz | 7 |
| 1CH | E2 / E1 / F1 / F3 / F4 / F5 のどれか 1ch | 中心 ±15 MHz | 4 |

各チャンネルには **9 MHz と 17 MHz** の帯域マーク（内側が濃い）を描く。
ホップが少ないほど更新が速い。

## 画面（320×240）

- 上段：モード／更新速度（sw/s）とフロア／ゲイン／ピークホールド
- スペクトラム：灰色が最新の掃引、白が平均（測定に使う線）、点線がピークホールド。
  縦の実線が実測中心、点線が公称周波数
- 周波数目盛り
- ウォーターフォール：0.5 秒 1 行（各行はその間のピーク）、新しい行が上
- 下段：チャンネルごとの実測中心、ずれ（±0.5 MHz 以内は青、1 MHz 未満は黄、それ以上は赤）、
  ピーク dB と -3 dB 幅。信号なしのときは理由（SNR 不足など）
- 1CH では、大きな実測中心に加えてピーク・SNR・フロア・-3 dB／-20 dB 幅を表示

## タッチ操作

抵抗膜式なので、少し押し込むように触る。上段のボタンは見た目より下（約 7 mm）まで反応する。

**メイン画面**

| 場所 | 動作 |
|---|---|
| 左上のモード（4CH など） | 4CH → 3CH → 1CH の切替 |
| SET | セットアップ画面を開く |
| HOLD | ピークホールドの ON/OFF（ON にするたびリセット） |
| スペクトラムかウォーターフォールを長押し（0.8 秒） | 平均・ホールド・ウォーターフォールのクリア |
| 1CH：下段左右の ◀ ▶ | チャンネル送り（E2 → E1 → F1 → F3 → F4 → F5 → E2 …） |

**セットアップ画面**（大きなボタン。− と ＋ は押し続けると連続で変わる。DONE で反映して戻る）

| 行 | 内容 |
|---|---|
| MODE | 4CH / 3CH / 1CH |
| 1CH | 1CH で表示するチャンネル |
| GAIN | ゲイン（テーブル番号 0〜60、60 の次が AGC。C5 は 55 以上で飽和） |
| SNR | 信号ありと判定する、フロアからの高さ（6〜30 dB、既定 18） |
| TOUCH CAL | タッチの調整 |

設定は保存され、次回もその状態で起動する。

**タッチの調整**：初回起動時に調整画面が出る（10 秒触らなければ既定値で起動）。
やり直すときは、起動直後の画面（約 1.5 秒）を押し続ける。

## 配線（XIAO ESP32-C5）

| 液晶基板のピン | XIAO | GPIO |
|---|---|---|
| SCK と T_CLK | D8 | 8 |
| SDI(MOSI) と T_DIN | D10 | 10 |
| T_DO | D9 | 9 |
| SDO(MISO) | 未接続 | – |
| CS | D0 | 1 |
| D/C | D1 | 0 |
| RESET | D4 | 23 |
| T_CS | D5 | 24 |
| T_IRQ | 未接続（ポーリング） | – |
| LED | D6 | 11 |
| VCC | 3V3（基板裏の J1 を短絡） | – |
| GND | GND | – |

D2/D3（GPIO25/7）はストラップピンなので使っていない。D6（GPIO11）は通常の ESP-SDR では UART に使うが、このビルドでは UART を切ってバックライトに使う。
電池で動かすときは XIAO の 5V ピンに電圧が出ないので、液晶の VCC は必ず 3V3 から取り、液晶基板の J1 を短絡する。
ピンや画面の向きは `main/fpv/fpv_config.h` で変えられる（`FPV_LCD_ROTATION` 1 か 3）。

## PC との接続（USB）

PC 版（fpv-band-monitor-c5）はこのファーム専用。XIAO の USB を PC につなぐと、チップで FFT・つなぎ合わせ済みの
**掃引を 1 回ごとに受け取る**（4CH で約 4 KB/掃引、I/Q の約 1/40）。液晶でも同じ掃引を表示し続ける。

- PC 版は起動時に `FPV?` で確かめ、PC のスパン・チャンネル（最大 4）・ゲインを送る。液晶は「PC」モード
  （上段に「PC」）になり、PC 版のチャンネルを表示する。
- 液晶のモードボタン（またはセットアップの MODE）で液晶側のモードに戻せる。ただし PC が接続中なら、
  PC は別スパンの掃引が 5 回続くと自分のスパンを送り直す（PC 側が優先）。
- PC 版のビン幅はファームと同じ 78.125 kHz。平均・重心・判定は PC 側で行う。
- 送られる値は dB を 0.01 dB 単位にしたもの（誤差 0.005 dB 以内）。
- `FPV` で始まらない行は ESP-SDR 本来の I/Q コマンド（FREQ・CAP20…）として処理するので、ESP-WebSDR などの
  I/Q を使うソフトもつながる（SPEC を使う機能は除く）。その間（最後のコマンドから 5 秒）は液晶の掃引を止め、
  「PC is using the receiver」と表示する。

**コマンド**（1 行ずつ。返事は 1 行。詳細は `main/fpv/link.h`）

| コマンド | 内容 |
|---|---|
| `FPV?` | 識別（`FPV 1 bin_hz=78125 …`） |
| `FPV STATE?` | 今の状態（モード・チャンネル・ゲイン・SNR・スパン・電池） |
| `FPV STREAM ON` / `OFF` | 掃引ごとの `SWEEP` フレーム送出 |
| `FPV MODE 4CH` / `3CH` / `1CH` | モード |
| `FPV CH F3` | 1CH のチャンネル（E2 E1 F1 F3 F4 F5） |
| `FPV GAIN 40` / `AGC` | ゲイン |
| `FPV SNR 18` | 判定の閾値（6〜30 dB） |
| `FPV SPAN 5670 5835 E2,E1,F3,F5` | 任意のスパン（4800〜6000 MHz、幅 175 MHz まで）とチャンネル |

フレーム：`SWEEP <連番> <開始MHz> <ビン数> <ビン幅Hz> <時刻ms> <CRC32>` の行のあと、ビン数 × uint16
（リトルエンディアン、dB = 値 / 100 − 200、0xFFFF はデータなし）。ビン k の中心は 開始 + (k + 0.5) × ビン幅。

`FPV` で始まらない行はすべて ESP-SDR 本来のコマンドとして処理するので、ESP-WebSDR などの I/Q を使う
ソフトもつながる（SPEC を使う機能は除く）。

## 電池駆動（低電圧シャットダウン）

XIAO 裏の BAT+／BAT− にリチウムイオン（1 セル）をつなぐ。電圧は XIAO 内蔵の分圧回路（GPIO26 で入切、GPIO6 で測定）で
2 秒ごとに測り、画面上段に表示する（低いと赤。USB だけで電池が無いときは「USB」）。

| 状況 | 動作 |
|---|---|
| 動作中に **3.30 V 未満が 3 回続く**（約 6 秒） | 「Battery low」を 3 秒表示 → 液晶をスリープ、バックライト消灯 → ディープスリープ |
| 電源投入・リセット時に 3.40 V 未満 | 理由を 3 秒表示してディープスリープ |
| シャットダウン中 | 60 秒ごとに起きて電圧だけ測る（液晶は点けない）。**3.70 V 以上**（充電された）なら通常起動 |

USB をつないで充電すると電圧が上がるので、次の確認（最大 60 秒後）で自動的に起動する。
しきい値は `main/fpv/fpv_config.h` の `FPV_BAT_*` で変えられる（`FPV_BAT_CUTOFF_MV 0` で無効）。

- 測定は掃引の合間に行い、無線の取り込み中には ADC を使わない。
- シャットダウン中もバックライト・液晶とタッチの CS・液晶 RESET を固定（ホールド）し、分圧回路は切る。
  残る消費は ESP32-C5 のディープスリープ、XIAO の 3V3 レギュレータ、スリープ中の液晶。
  それでも電池は少しずつ減るので、シャットダウン後は早めに充電する。
- 電池保護回路（多くのセルで 2.5〜3.0 V）より上で止めるのが目的。3.30 V は負荷がかかった状態の値で、
  止めると電圧が戻って 3.4 V 台になる。

## 書き込み

ビルド済みの `firmware/fpv-lcd-xiao-c5-merged.bin` を **オフセット 0x0** に書く（8 MB フラッシュ用）。

```
python -m esptool --chip esp32c5 write-flash 0x0 firmware/fpv-lcd-xiao-c5-merged.bin
```

ブラウザなら [ESP Tool](https://espressif.github.io/esptool-js/) で、Flash Address 0x0 に同じファイルを指定する。

## ビルド

ESP-IDF は ESP-SDR が固定している版（`firmware-targets.json` の esp32c5、6.2 系）を使う。
LovyanGFX は同梱していないので、先に取得する（動作確認した版は 1.2.32、コミット e2cc321）。

```
git clone https://github.com/lovyan03/LovyanGFX components/LovyanGFX
git -C components/LovyanGFX checkout e2cc321
idf.py -B build-fpv -D FPV_LCD_MONITOR=ON -D SDKCONFIG=build-fpv/sdkconfig \
  -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.defaults.esp32c5;sdkconfig.defaults.fpv-lcd" \
  set-target esp32c5 build
idf.py -B build-fpv -p PORT flash
```

`-D FPV_LCD_MONITOR=ON` を付けなければ、従来どおりの ESP-SDR（USB で PC 版やブラウザ版を使う）になる。

## PC 版との違い

- **FFT は 1024 点**（ビン幅 78.125 kHz）。C5 には FPU が無いので 32bit 整数 FFT（Q31 係数、MULH 1 命令、段ごとに 1/2）にし、2 のべき乗にした（PC 版は 800 点・100 kHz）。最初の 2 段は掛け算なし。平均（DC）除去はホップごとに 1 回（PC 版は 1024 サンプルごと。差が出るのは捨てている LO ±500 kHz だけ）。
- **平均は直近 10 掃引の単純平均**（PC 版は直近 3 秒間の掃引すべて）。10 掃引分（約 92 KB）を PSRAM に保存し、掃引ごとに入れ替える。平均の計算方法（リニア電力で平均、掃引が届かなかったビンは除く）は PC 版と同じ。回数は `main/fpv/fpv_config.h` の `FPV_AVG_SWEEPS` で変えられる。
- ホップ（25 MHz 間隔・片側 28 MHz 使用・LO ±500 kHz 除外・小さい方を採用）、
  重心による中心周波数（±7.5 MHz、フロア +3 dB 超のみ、再センタリング 1 回）、
  SNR 18 dB の在り判定、-3／-20 dB 幅、表示の平滑化（0.3）は PC 版と同じ。
- メモリの都合で、ESP-SDR のオンチップスペクトラム（SPEC コマンド）はこのビルドから外している
  （CAPS にも出さない）。

## 動作確認

- PC 上で、液晶版の FFT・スティッチ・解析を PC 版の Python 実装と同じ疑似キャプチャで比較：
  スティッチ後のスペクトラムの差は最大 0.09 dB、実測中心の差は 0.001 MHz 以内、在り判定は全一致、
  10 掃引平均は PC 版の SpectrumAverager と一致
- USB の往復（`tests/fpv_host/check_link.py`）：ファームの符号化（C）→ 疑似シリアル → PC 版の受信 → 表示格子と測定。
  格子はファームと同じ 2112 ビン、値の差 0.005 dB 以内、実測中心の差 0.001 MHz 以内。
  （`tests/fpv_host/check_dsp.py`）。
- 画面は同じ描画コードを PC で動かして確認（`tests/fpv_host/render_previews.py`）。
- **実機（XIAO ESP32-C5 + 液晶）ではまだ動かしていない。** 掃引速度（画面上段の sw/s）、
  PSRAM の認識、タッチの向きは実機で確かめる必要がある。

## 速度の見積もり

`tests/fpv_host/cycles/` で、計算部分を RV32IMAC の命令として PC 上で実行し、命令数から 240 MHz での時間を出した
（1 命令あたりのクロックは楽観〜悲観の幅）。描画は部分更新（スペクトラム最大 10 回/秒、ウォーターフォールは行追加時、
数値 4 回/秒、上段 1 回/秒）で、SPI 40 MHz の転送中は CPU が待つとした。再同調 0 ms のとき：

| モード | PC 版（USB） | 液晶版 |
|---|---|---|
| 4CH | 約 3.6 掃引/秒 | 5.0〜6.4 掃引/秒 |
| 3CH | 約 4.6 | 6.2〜7.8 |
| 1CH | 約 8.1 | 9.4〜12（画面は最大 10 回/秒） |

再同調（周波数を変えるたびの DC 再校正）の時間は含まない。実機の値は画面上段の sw/s で確認する。
