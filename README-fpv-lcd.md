# FPV バンドモニタ 液晶版（XIAO ESP32-C5 + Waveshare 3.5" 静電容量式）

[fpv-band-monitor-c5](https://github.com/zubon2003/fpv-band-monitor-c5)（PC 版）の解析と画面を、
ESP32-C5 単体で動くように [ESP-SDR](https://github.com/ESPARGOS/esp-sdr) ファームに組み込んだもの。
PC は不要で、Waveshare 3.5inch Capacitive Touch LCD（3.5" 480×320、ST7796S + FT6336U）に
スペクトラム・ウォーターフォール・実測中心周波数を表示する。
（2.8" ILI9341 版と Pico-ResTouch-LCD-3.5 版は 2026-11-28 に削除した。）
**アナログ FPV の映像電波（FM-ATV）専用**。

追加したコードは `main/fpv/` にまとまっている。ESP-SDR 側の変更は
`main/families/c5_c6_c61/receiver.c` に、無線を直接操作する小さな関数群（`sdr_hw_*`）と、
起動時にモニタへ入る分岐を足しただけ。

## 表示モード

| モード | チャンネル | 掃引範囲 | ホップ数 |
|---|---|---|---|
| 4CH（既定） | E2 / E1 / F3 / F5 | 5670〜5835 MHz | 9 |
| 4CH2 | E1 / A8 / A5 / F5 | 5690〜5835 MHz | 8 |
| 4CH3 | R2 / F1 / R4 / R5 | 5680〜5821 MHz | 8 |
| 3CH | E1 / F1 / F4 | 5690〜5815 MHz | 7 |
| 1CH | 表示中のグループのチャンネルのどれか 1ch | 中心 ±15 MHz | 4 |

各チャンネルには **9 MHz と 17 MHz** の帯域マーク（内側が濃い）を描く。
ホップが少ないほど更新が速い。

## 画面（480×320）

- 上段：表示中のチャンネル（チャンネルの色で）／電池（残量アイコンと電圧、USB 給電なら USB）／SETUP／HOLD
- スペクトラム：灰色が最新の掃引、白が平均（測定に使う線）、点線がピークホールド。
  縦の実線が実測中心、点線が公称周波数。ADC が飽和すると右上に赤い **SAT nn%**（ゲインを下げる）
- 周波数目盛り
- ウォーターフォール：0.5 秒 1 行（各行はその間のピーク）、新しい行が上
- 下段：チャンネルごとのカード。**ずれ（MHz）を大きく**表示し、カードの地もずれの色
  （±0.5 MHz 以内は青、1 MHz 未満は黄、それ以上は赤）。その下に実測中心。
  電波が無ければ NO SIGNAL、弱ければ WEAK
- 3CH・4CH の色は周波数の低い順に 赤・緑・青・黄
- 1CH では、ずれを大きく、右に実測中心・SNR・ピーク・帯域幅（-3 dB / -20 dB）

## タッチ操作

上段のボタンは見た目より下（約 7 mm）まで反応する。

**メイン画面**

| 場所 | 動作 |
|---|---|
| 左上のチャンネル表示（▼） | モード一覧を開く |
| SETUP | セットアップ画面を開く |
| HOLD | ピークホールドの ON/OFF（ON にするたびリセット） |
| スペクトラムかウォーターフォールを長押し（0.8 秒） | 平均・ホールド・ウォーターフォールのクリア |
| 3CH・4CH：下段のカード | そのチャンネルの 1CH 表示へ |
| 1CH：下段左右の ◀ ▶ | グループ内でチャンネル送り（4CH なら E2 → E1 → F3 → F5 → E2 …） |
| 1CH：下段の中央 | グループの表示に戻る |

**モード一覧**：グループ（4CH / 4CH2 / 4CH3 / 3CH）ごとの行に、チャンネルと周波数をグループの色で表示。
行を押すとそのグループになる。1CH はグループに属し、カードを押して入る（色もグループでの色のまま）。
CLOSE で何も変えずに戻る。

**WiFi チェック**（モード一覧の各行の右端 **WiFi**）：そのグループに効く Wi-Fi チャンネルだけを、
1.2 秒ずつ**受信だけで**聞く（電波は出さない。その間 FPV の掃引は止まる）。
- 聞くチャンネルは事前計算：ch100〜177 の 20 MHz チャンネルのうち、グループのチャンネル（17 MHz）に
  **Direct**（重なる）か **IMD**（2×VTX−WiFi、2×WiFi−VTX の 3 次積が乗る）になるものだけ（13〜18 ch）
- 上：周波数マップ（5490〜5900 MHz）にグループのチャンネルと、聞く Wi-Fi チャンネル
  （灰＝未、暗＝何も無し、赤＝Direct になる電波あり、黄＝IMD になる電波あり）
- 下：グループのチャンネルごとに **OK** / **Direct** / **IMD**。原因の Wi-Fi ch・dBm・IMD の組み合わせ
  （例 `2xE2-WiFi`）・AP 名（ビーコンが聞こえた場合）。原因が複数なら `+n more`
- 幅の広い AP（80/160 MHz）は、副チャンネルでもフレームが聞こえるので判定に入る。AP 名は主チャンネルを
  聞いたときだけわかる
- SCAN / STOP でやり直し・中止、CLOSE で戻る

**セットアップ画面**（− と ＋ は押し続けると連続で変わる。DONE で反映して戻る）

| 行 | 内容 |
|---|---|
| GAIN | ゲイン（テーブル番号 0〜60、60 の次が AUTO。C5 は 55 以上で飽和しやすい。飽和中は赤で表示） |
| DETECT | 信号ありと判定する、ノイズからの高さ（6〜30 dB、既定 18） |
| INFO | 掃引の速さ、ノイズの床、電池、受信エラー（開いた時点の値） |
| SCREEN | ROTATE 180：画面とタッチを 180 度回す（押すとすぐ切り替わって保存される） |

設定は保存され、次回もその状態で起動する。

**タッチの調整**はない（2026-11-28 に削除）。座標は `main/fpv/monitor.cpp` のタッチ設定（`x_min`〜`y_max`）だけで決まる。
以前のファームが保存した校正値は起動時に消す。

## 液晶と配線（XIAO ESP32-C5）

液晶は Waveshare 3.5inch Capacitive Touch LCD（SKU 29318、ST7796S + FT6336U）。タッチは I2C で、校正はしない。
結線図：[captouch35.html](https://zubon2003.github.io/fpv-lcd/wiring/captouch35.html)。

液晶の裏に重ねる本体基板（FFC 版）は `hardware/captouch35_ffc/`（KiCad 8 の基板、`jlcpcb/` にガーバー・BOM・CPL）。
液晶とは 18 ピン 0.5 mm の FFC でつなぐ。詳しくは同フォルダの README。

| 液晶のピン（Interface 2） | XIAO | GPIO |
|---|---|---|
| VCC、3V3 | 3V3 | – |
| GND | GND | – |
| MISO | 未接続 | – |
| MOSI | D10 | 10 |
| SCLK | D9 | 9 |
| SD_CS | 未接続（TF スロットは空のまま） | – |
| LCD_CS | D8 | 8 |
| LCD_DC | D7 | 12 |
| LCD_RST | D6 | 11 |
| LCD_BL | D5 | 24 |
| TP_SDA | D4 | 23 |
| TP_SCL | D1 | 0 |
| INT | 未接続（ポーリング） | – |
| RST（タッチ） | D0 | 1 |

D2/D3（GPIO25/7）はストラップピンなので使っていない。D6/D7（GPIO11/12）は通常の ESP-SDR では UART に使うが、このビルドでは UART を切って液晶に使う。
ピンや画面の向きは `main/fpv/fpv_config.h` で変えられる（`FPV_LCD_ROTATION` 1 か 3）。

## PC との接続（USB）

PC 版（fpv-band-monitor-c5）は 2 つの受信方式でこのファームにつながる。画面上部の **Rx: auto / iq / fft** ボタン
（起動時は `--receiver`）で選ぶ。

| 方式 | 動作 |
|---|---|
| `auto`（既定） | 接続のたびに `FPV?` を送り、このファームが答えれば `fft`、答えなければ（通常の ESP-SDR）`iq` |
| `fft` | チップで FFT・つなぎ合わせ済みの**掃引を 1 回ごとに受け取る**（4CH で約 4 KB/掃引、I/Q の約 1/40）。液晶でも同じ掃引を表示し続ける |
| `iq` | ESP-SDR 本来の I/Q を受け取り PC で FFT。その間（最後のコマンドから 5 秒）は液晶の掃引を止め「PC is using the receiver (I/Q)」と表示 |

- `fft` では PC 版がスパン・チャンネル（最大 4）・ゲインを送る。液晶は「PC」モード（上段に「PC」）になり、PC 版のチャンネルを表示する。
- 液晶のモードボタン（またはセットアップの MODE）で液晶側のモードに戻せる。ただし PC が接続中なら、
  PC は別スパンの掃引が 5 回続くと自分のスパンを送り直す（PC 側が優先）。
- `fft` のビン幅はファームと同じ 78.125 kHz（`iq` は PC 版の `--bin-khz`、既定 100 kHz）。平均・重心・判定は PC 側で行う。
- 送られる値は dB を 0.01 dB 単位にしたもの（誤差 0.005 dB 以内）。

**液晶オフ（NOLCD）**：PC 版の **No LCD**（または `--nolcd`）で `FPV NOLCD` を送ると、液晶をスリープ・バックライト消灯にし、
画面用の処理（平均・判定・描画）をやめて、CPU を掃引と FFT だけに使う（ESP32-C5 は 1 コアなので描画の分だけ速くなる）。
次のどれかで表示が戻る：`FPV LCD`、`FPV STREAM OFF`（PC 版の Disconnect・終了）、PC からの送信が止まって掃引フレームを送れなくなったとき、液晶のタップ。

**コマンド**（1 行ずつ。返事は 1 行。詳細は `main/fpv/link.h`）

| コマンド | 内容 |
|---|---|
| `FPV?` | 識別（`FPV 1 bin_hz=78125 …`） |
| `FPV WIFI 100 1500` | Wi-Fi ch100 を 1500 ms 受信だけで聞き、フレーム数と AP（SSID・占有 MHz・dBm）を返す（END まで複数行） |
| `FPV STATE?` | 今の状態（モード・チャンネル・ゲイン・SNR・スパン・電池・飽和 clip（千分率）） |
| `FPV STREAM ON` / `OFF` | 掃引ごとの `SWEEP` フレーム送出 |
| `FPV MODE 4CH` / `4CH2` / `4CH3` / `3CH` / `1CH` | グループ、または今のグループの 1CH |
| `FPV CH F3` | 1CH のチャンネル（今のグループのチャンネルのみ） |
| `FPV GAIN 40` / `AGC` | ゲイン |
| `FPV SNR 18` | 判定の閾値（6〜30 dB） |
| `FPV SPAN 5670 5835 E2,E1,F3,F5` | 任意のスパン（4800〜6000 MHz、幅 175 MHz まで）とチャンネル |
| `FPV NOLCD` / `FPV LCD` | 液晶を消して掃引だけ行う／表示に戻す |

フレーム：`SWEEP <連番> <開始MHz> <ビン数> <ビン幅Hz> <時刻ms> <CRC32>` の行のあと、ビン数 × uint16
（リトルエンディアン、dB = 値 / 100 − 200、0xFFFF はデータなし）。ビン k の中心は 開始 + (k + 0.5) × ビン幅。

`FPV` で始まらない行はすべて ESP-SDR 本来のコマンドとして処理するので、ESP-WebSDR などの I/Q を使う
ソフトもつながる（SPEC を使う機能は除く）。

## 電池駆動（低電圧シャットダウン）

XIAO 裏の BAT+／BAT− にリチウムイオン（1 セル）をつなぐ。電圧は XIAO 内蔵の分圧回路（GPIO26 で入切、GPIO6 で測定）で
2 秒ごとに測り、画面上段に表示する（低いと赤。USB だけで電池が無いときは「USB」）。

| 状況 | 動作 |
|---|---|
| 動作中に **3.30 V 未満が 3 回続く**（約 6 秒） | 「Battery low」を 3 秒表示 → 液晶をスリープ、バックライト消灯 → ディープスリープ |
| 電源投入・リセット時に 3.40 V 未満 | 理由を 3 秒表示してディープスリープ |
| シャットダウン中 | 60 秒ごとに起きて電圧だけ測る（液晶は点けない）。**3.70 V 以上**（充電された）なら通常起動 |

USB をつないで充電すると電圧が上がるので、次の確認（最大 60 秒後）で自動的に起動する。
しきい値は `main/fpv/fpv_config.h` の `FPV_BAT_*` で変えられる（`FPV_BAT_CUTOFF_MV 0` で無効）。

- 測定は掃引の合間に行い、無線の取り込み中には ADC を使わない。
- シャットダウン中もバックライト・液晶の CS・液晶 RESET を固定（ホールド）し、分圧回路は切る。
  残る消費は ESP32-C5 のディープスリープ、XIAO の 3V3 レギュレータ、スリープ中の液晶。
  それでも電池は少しずつ減るので、シャットダウン後は早めに充電する。
- 電池保護回路（多くのセルで 2.5〜3.0 V）より上で止めるのが目的。3.30 V は負荷がかかった状態の値で、
  止めると電圧が戻って 3.4 V 台になる。

## 書き込み

ブラウザから書くなら https://zubon2003.github.io/fpv-lcd/ 。
ファイルで書くなら `web/firmware/fpv-lcd-xiao-c5-captouch35.bin` を **オフセット 0x0** に書く（8 MB フラッシュ用）。

```
python -m esptool --chip esp32c5 write-flash 0x0 web/firmware/fpv-lcd-xiao-c5-captouch35.bin
```

## ビルド

ESP-IDF は ESP-SDR が固定している版（`firmware-targets.json` の esp32c5、6.2 系）を使う。
LovyanGFX は同梱していないので、先に取得する（動作確認した版は 1.2.32、コミット e2cc321）。

```
git clone https://github.com/lovyan03/LovyanGFX components/LovyanGFX
git -C components/LovyanGFX checkout e2cc321
idf.py -B build-fpvcap -D FPV_LCD_MONITOR=ON -D SDKCONFIG=build-fpvcap/sdkconfig \
  -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.defaults.esp32c5;sdkconfig.defaults.fpv-lcd" \
  set-target esp32c5 build
idf.py -B build-fpvcap -p PORT flash
```

`-D FPV_LCD_MONITOR=ON` を付けなければ、従来どおりの ESP-SDR（USB で PC 版やブラウザ版を使う）になる。

## PC 版との違い

- **FFT は 1024 点**（ビン幅 78.125 kHz）。C5 には FPU が無いので 32bit 整数 FFT（Q31 係数、MULH 1 命令、段ごとに 1/2）にし、2 のべき乗にした（PC 版は 800 点・100 kHz）。最初の 2 段は掛け算なし。平均（DC）除去はホップごとに 1 回（PC 版は 1024 サンプルごと。差が出るのは捨てている LO ±500 kHz だけ）。
- **平均は直近 10 掃引の単純平均**（PC 版は直近 3 秒間の掃引すべて）。10 掃引分（約 92 KB）を PSRAM に保存し、掃引ごとに入れ替える。平均の計算方法（リニア電力で平均、掃引が届かなかったビンは除く）は PC 版と同じ。回数は `main/fpv/fpv_config.h` の `FPV_AVG_SWEEPS` で変えられる。
- ホップ（25 MHz 間隔・片側 28 MHz 使用・LO ±500 kHz 除外・小さい方を採用）、
  重心による中心周波数（±7.5 MHz、フロア +3 dB 超のみ、再センタリング 1 回）、
  SNR 18 dB の在り判定、-3／-20 dB 幅、表示の平滑化（0.3）は PC 版と同じ。
- メモリの都合で、ESP-SDR のオンチップスペクトラム（SPEC コマンド）はこのビルドから外している
  （CAPS にも出さない）。

## 動作確認

- PC 上で、液晶版の FFT・スティッチ・解析を PC 版の Python 実装と同じ疑似キャプチャで比較：
  スティッチ後のスペクトラムの差は最大 0.09 dB、実測中心の差は 0.001 MHz 以内、在り判定は全一致、
  10 掃引平均は PC 版の SpectrumAverager と一致
- USB の往復（`tests/fpv_host/check_link.py`）：ファームの符号化（C）→ 疑似シリアル → PC 版の受信 → 表示格子と測定。
  格子はファームと同じ 2112 ビン、値の差 0.005 dB 以内、実測中心の差 0.001 MHz 以内。
  （`tests/fpv_host/check_dsp.py`）。
- 画面は同じ描画コードを PC で動かして確認（`tests/fpv_host/render_previews.py`）。
- 実機（XIAO ESP32-C5 + 3.5" 静電容量式）で表示・タッチ・掃引を確認済み（2026-10-14〜）。

## 速度の見積もり

`tests/fpv_host/cycles/` で、計算部分を RV32IMAC の命令として PC 上で実行し、命令数から 240 MHz での時間を出した
（1 命令あたりのクロックは楽観〜悲観の幅）。描画は部分更新（スペクトラム最大 10 回/秒、ウォーターフォールは行追加時、
数値 4 回/秒、上段 1 回/秒）で、SPI 40 MHz の転送中は CPU が待つとした。再同調 0 ms のとき：

| モード | PC 版（USB） | 液晶版 |
|---|---|---|
| 4CH | 約 3.6 掃引/秒 | 5.0〜6.4 掃引/秒 |
| 3CH | 約 4.6 | 6.2〜7.8 |
| 1CH | 約 8.1 | 9.4〜12（画面は最大 10 回/秒） |

再同調（周波数を変えるたびの DC 再校正）の時間は含まない。実機の値は画面上段の sw/s で確認する。
