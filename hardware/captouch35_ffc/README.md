# バンドモニター本体基板 (FFC 版) + 電池サブ基板

Waveshare 3.5inch Capacitive Touch LCD の裏に M2.5 の六角スペーサー (長さ 15mm、オス-メス) で重ねる XIAO ESP32-C5 の基板。
液晶とは 18 ピンの FFC (0.5mm) でつなぐ。電池のサブ基板 (BT2.0 だけ) を右にミシン目でつないだ 1 枚のパネル。
ピンは fpv_config.h の FPV_PANEL_CAPTOUCH35 と同じなので、ファームは今のまま使える。

- `captouch35_ffc.kicad_pcb`: KiCad 8 の基板 (回路図はない。結線は下のとおり)。フットプリントは `captouch35_ffc.pretty`
- `drc.rpt`: DRC の結果 (違反 0、未接続 0)
- `jlcpcb/`: ガーバー zip、BOM、CPL (部品の位置)
- `preview_top.pdf` (外側から見た図)、`preview_bottom.pdf` (液晶側)、`preview.svg`

## 形
- 本体: 83.44 x 55.16mm (液晶の基板と同じ)。M2.5 の穴が四隅 (端から 4.8mm)、液晶の穴と同じ位置
- 図は外側 (液晶と反対の面) から見たもの。液晶を裏から見た向きと同じ
- XIAO: 外側の面、USB-C は下の辺 (1.3mm はみ出す)、U.FL は上を向く → SMA のピグテールで上へ
- FFC: 液晶のコネクタ (裏の右端) のすぐ左にスロット (1.6 x 12mm) があり、ケーブルはそこから外側へ抜けて左へ進み、J1 に入る
- ロゴ (シルク): ZUBON TECH. (上) と Tinywhoop (右下)。基板ファイルに入っている
- サブ基板: 12 x 16mm、M2 の穴 2 つ。本体の右の辺とタブ (幅 5mm、Ø0.5 の穴 5 つ x 2 列) でつながっている。手で折って外す

| 4 | SCLK | D9 | 表 |
| 5 | MOSI | D10 | 表 |

## 組み立ての注意
- **XIAO を付ける前に**、XIAO の裏の BAT+ / BAT- のパッドに電線を付け、上 (アンテナ側) へ出しておく (付けた後は基板とのすき間に隠れる)
- 液晶側に出たピンヘッダーの足は短く切る (液晶の裏の部品に当たらないように。設計時の想定はすき間 8mm)
- FFC は両面接点なので、ケーブルの接点の向き (A/B) は気にしなくてよい。ピン 1 は液晶側もこちらも上の端
- 長さ 50mm は計算上の値 (液晶のコネクタ → スロット → J1)。余ったらスロットの外側で軽くたわませる

## 注文前に確かめること
- `preview_top.pdf` を原寸で印刷し、液晶の裏に重ねて、四隅の穴と FFC コネクタの位置 (スロットのすぐ右に来るか) を確かめる。
  液晶のコネクタの位置は、Waveshare の 3D データから読んだ値
