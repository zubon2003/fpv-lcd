XIAO ESP32-C5 × Waveshare Pico-ResTouch-LCD-3.5 結線図

液晶版ファーム FPV_PANEL=RESTOUCH35（main/fpv/fpv_config.h）のピン配置。液晶は ILI9488（16 bit パラレルを SPI からシフトレジスタで駆動）、タッチは XPT2046（抵抗膜、SPI）。液晶とタッチは SCLK・MOSI・MISO を共有する。

ふつうは下駄基板で挿すだけです。 この基板は Raspberry Pi Pico 用のソケットを持つので、Pico と同じ外形・ピン位置に XIAO を載せる下駄基板 （hardware/xiao_restouch35_adapter）を作ってあります。 この図はその配線と同じで、ジャンパ線でつなぐときや確認に使います。LCD 側の表示は「信号名・Pico の GPIO・Pico のピン番号」。

接続図（XIAO は部品面から見て USB-C が上）

電源 VSYS GND SPI（液晶とタッチで共有） リセット・バックライト タッチ CS

D2（GPIO25）と D3（GPIO7）は起動モードを決めるピンなので空けておく。D8（GPIO8）と XIAO の 3V3 も使わない。

つなぐ前の確認

  • 電源は VSYS へ。USB だけで動かすなら XIAO の 5V から。電池で動かすときは XIAO の 5V 端子に電圧が出ないので、XIAO 裏の BAT+ から線でつなぐ。
  • SD カードは入れない（SD_CS を使っていないので、カードが MISO を乱すおそれがある）。
  • 初回起動時にタッチの校正画面が出る（抵抗膜式なので少し押し込むように触る）。
  • 色が反転していたら FPV_LCD_INVERT を false に、表示が乱れるなら FPV_LCD_SPI_HZ を 10 MHz に下げる。
