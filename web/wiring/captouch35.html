XIAO ESP32-C5 × Waveshare 3.5inch Capacitive Touch LCD 結線図

液晶版ファーム FPV_PANEL=CAPTOUCH35（main/fpv/fpv_config.h）と同じピン配置。液晶は ST7796S（SPI）、タッチは FT6336U（I2C、0x38）。

LCD 側はケーブルの表示名で合わせてください。 タッチの割り込みとリセットは、ケーブルでは INT と RST と書かれています（LCD_RST とは別の線）。 下の接続図は線が交差しない順に並べてあり、コネクタの実際の並びは「コネクタの並び」を見てください。

接続図（XIAO は部品面から見て USB-C が上）

電源 3.3V GND 液晶 SPI リセット・バックライト タッチ I2C

コネクタの並び（実物、1 番ピンから）

上段がピン番号、枠の中がケーブルの表示、下段がつなぐ XIAO の端子。点線の枠（MISO・SD_CS・INT）はつながない。

ピン対応表（実物の並び）

ピンケーブル表示XIAO 端子GPIO役割

23V33V3—VCC と同じ 3V3 へ
3GNDGND—
4MISO——つながない

D2（GPIO25）と D3（GPIO7）は起動モードを決めるピンなので空けておく。D6/D7 は ESP-SDR の UART ですが、液晶版ファームでは使っていません。

つなぐ前の確認

  • VCC は 3V3 へ。このモジュールは電源電圧が信号の電圧になるので、5V につなぐと C5 に 5V が入るおそれがあります。
  • ケーブルに VCC と 3V3 の両方があれば、両方とも XIAO の 3V3 へ。
  • 電池で動かすときも 3V3 から取る（電池だけのとき XIAO の 5V 端子には電圧が出ません）。
  • TF カードは入れない（SD_CS をつないでいないため）。

ファーム

このパネル用のビルド（-D FPV_PANEL=CAPTOUCH35）を 0x0 に書く。実機で動作確認済み（2026-10-14）。 ブラウザからの書き込みページは、今のところ 3.5" ResTouch と 2.8" 版だけ。

python -m esptool --chip esp32c5 --port COMx write-flash 0x0 fpv-lcd-xiao-c5-captouch35-merged.bin
