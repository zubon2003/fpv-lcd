FPV バンドモニタ ファーム書き込み

XIAO ESP32-C5 で動く FPV 5.8 GHz（FM-ATV）バンドモニタ・液晶版のファームを、ブラウザから USB で書き込みます。グループ（4CH / 4CH2 / 4CH3 / 3CH）の監視、グループごとの Wi-Fi チェック（受信のみ）とグループ内 IMD の表示、PC 版（fft / iq）との接続に対応。

1. 液晶を選ぶ

結線図：3.5" Pico-ResTouch-LCD-3.5 ・ 3.5" Capacitive Touch LCD（静電容量式）

2. つないで書き込む

このブラウザは USB 書き込み（Web Serial）に対応していません。パソコンの Chrome か Edge で開いてください。 このページは https で開く必要があります。

ファームのバージョン 442c958 ・ チップ ESP32-C5 ・ アドレス 0x0 に 1 ファイル

  1. XIAO ESP32-C5 を USB-C でパソコンにつなぐ。
  2. 「書き込む」を押し、出てきた一覧から XIAO のポート（USB JTAG/serial debug unit、Windows では「USB シリアル デバイス (COMx)」）を選ぶ。
  3. 「消去してから書き込む」を選ぶと、保存した設定（モード・ゲイン・タッチ校正）も消える。ふつうは消去しなくてよい。
  4. 終わったら XIAO の RESET を 1 回押す。ResTouch は初回に液晶へタッチ校正の画面が出る（10 秒触らなければ既定値で進む）。静電容量式は校正不要。

つながらないとき：XIAO の BOOT を押したまま RESET を押して離し、BOOT を離してから、もう一度「書き込む」。他のアプリ（PC 版モニタ、ESP-WebSDR など）がポートを使っていたら閉じる。

コマンドで書く場合

ファイルを保存して esptool で 0x0 に書き込む： 3.5" ResTouch 版 ・ 3.5" 静電容量式版

python -m esptool --chip esp32c5 write-flash 0x0 fpv-lcd-xiao-c5-restouch35.bin

ソース：zubon2003/fpv-lcd（ESPARGOS/esp-sdr のフォーク、GPL-3.0）・ PC 版：zubon2003/fpv-band-monitor-c5

書き込みは ESPHome の ESP Web Tools（中身は Espressif の esptool-js）を使っています。
